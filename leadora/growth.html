Required setup — API keys
  1. Company search: add BRAVE_SEARCH_API_KEY.
  2. AI writing: add GEMINI_API_KEY (preferred) or OPENROUTER_API_KEY.
  3. Email sending: add RESEND_API_KEY and LEADORA_FROM_EMAIL using a sender domain verified in Resend.
  4. Open Supabase → Project Settings → Edge Functions → Secrets. Save each key there. Never paste secret keys into this page or public GitHub files.
